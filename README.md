# EditWave

Десктопный аудиоредактор на C# / WPF для базовой обработки звука: обрезка, реверс, усиление, экспорт.

## Стек

- **C# / .NET 8** — WPF приложение
- **NAudio** — воспроизведение и обработка аудио
- **LiteDB** — хранение проектов
- **MVVM** — архитектура приложения

## Возможности

- Воспроизведение WAV и MP3
- Обрезка и удаление выделенного фрагмента
- Реверс и усиление (полное или выделенной области)
- Undo / Redo (до 5 шагов)
- Экспорт в WAV и MP3
- Сохранение и загрузка проектов
- Визуализация звуковой волны

## Запуск

1. Клонировать репозиторий
2. Открыть `EditWave.sln` в Visual Studio
3. Скачать [lame.exe](http://lame.sourceforge.net/) и положить в корень проекта (нужен для экспорта в MP3)
4. Запустить
